## Content and training QA

- [ ] Every source block, cover descriptor, image label, table cell, note and appendix is mapped to Korean content.
- [ ] All  source issues have a documented coach/editor resolution; missing text was recovered from evidence.
- [ ] Program duration, days, exercise order, sets, reps, loads, percentages, RPE, rest, tempo and sides match approved source.
- [ ] Supersets, drop sets, rest-pause, alternatives and all if/then conditions retain their meaning.
- [ ] Nutrition quantities, units, food alternatives and timing match approved source; no undocumented unit conversions.
- [ ] Numeric checker findings and approved exceptions reviewed manually in context.
- [ ] Korean is natural and consistent with glossary; proper names and intended English terms are documented.
- [ ] No English body passages remain unintentionally; text inside images checked separately.
- [ ] Coaching claims and audience/intensity wording checked against the approved English source.

## PDF QA

- [ ] Every final page rendered and inspected; tracker links each source page to final target pages.
- [ ] Korean fonts embedded and searchable/copyable text verified; no missing glyph boxes or replacement characters.
- [ ] No clipping, overlaps, tiny table text, hidden instructions or orphaned RPE/rest lines.
- [ ] Contents, bookmarks, numbering and cross-references match final pagination.
- [ ] Original visuals preserved appropriately and all required image text localized.
- [ ] All intended demonstration links recovered and tested; no invented destinations.
- [ ] Desktop and phone PDF opening/readability checked.
- [ ] PDF metadata records Korean language, correct title, edition and author.

## Delivery and ongoing parity

- [ ] Final asset is private, distinct from the English file, and included in both fulfillment function bundles.
- [ ] Server-side product mapping explicitly selects the purchased file language.
- [ ] Cart, checkout, confirmation and email describe the same language and edition.
- [ ] Test-mode fulfillment attaches the correct readable file; mixed carts and missing files checked.
- [ ] Repeat fulfillment does not send duplicate messages; previous English purchase behavior remains correct.
- [ ] Source hash and Korean hash recorded; previous release retained for rollback.
- [ ] Release tracker updated only after all above checks; future English changes trigger `needs_update`.
